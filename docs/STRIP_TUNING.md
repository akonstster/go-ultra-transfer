# Полоса кусков проекта — настройки

Все значения, от которых зависит вид и «ощущение» полосы кусков на экране проекта, собраны в одном файле:
[`android/app/src/main/java/app/goultra/transfer/ui/StripTuning.kt`](../android/app/src/main/java/app/goultra/transfer/ui/StripTuning.kt).
Поменяйте значение там и пересоберите приложение. Код полосы (`ProjectScreen.kt`) трогать не нужно.

## Как работает перенос

Долгое нажатие на карточку поднимает её: карточка увеличивается, приподнимается, под ней появляется тень, и дальше
она идёт за пальцем. Пока карточку держат на месте или ведут медленно, полоса не меняется: остальные карточки только
раздвигаются, освобождая место, куда она упадёт (место обведено рамкой). Если резко провести карточку вбок (быстрее
`GATHER_SPEED`), остальные уменьшаются вокруг неё, и на экране их помещается больше; уменьшенной полоса остаётся до
отпускания. Если поднести карточку к краю полосы, полоса прокручивается сама. После отпускания карточка садится на
своё место, а полоса возвращается к обычному размеру.

## Размеры

| Константа | Сейчас | Что делает |
|---|---|---|
| `CARD_W` | 92 dp | Ширина карточки; высота = ширина / 1.5. Больше — крупнее кадр и кнопки, меньше карточек на экране |
| `CARD_GAP` | 8 dp | Промежуток между карточками |
| `STRIP_EDGE` | 12 dp | Отступ перед первой и после последней карточки |

## Перенос карточки

| Константа | Сейчас | Что делает |
|---|---|---|
| `GATHER_SPEED` | 900 dp/с | С какой скорости бокового движения карточки остальные уменьшаются. Больше — нужен более резкий рывок; 0 — уменьшаются сразу при взятии |
| `CARRY_SCALE` | 0.6 | Во сколько раз уменьшаются остальные карточки после резкого движения вбок. Меньше — «дальше», больше карточек на экране (0.6 ≈ в 1.6 раза больше); 1.0 — без уменьшения |
| `LIFT_SCALE` | 1.1 | Во сколько раз увеличивается поднятая карточка |
| `LIFT_RISE` | 10 dp | На сколько поднятая карточка приподнимается над полосой |
| `LIFT_SHADOW` | 12 dp | Глубина тени под поднятой карточкой; 0 — без тени |
| `LIFT_FOLLOW_Y` | 0.35 | Какую долю вертикального движения пальца повторяет карточка (0 — только по горизонтали, 1 — точно за пальцем). На место падения не влияет |
| `LIFT_MAX_Y` | 28 dp | Насколько далеко вверх или вниз карточка может уйти от полосы |

## Прокрутка у краёв

| Константа | Сейчас | Что делает |
|---|---|---|
| `EDGE_ZONE` | 0.18 | Ширина зоны у каждого края (доля ширины полосы), в которой полоса прокручивается сама |
| `EDGE_SPEED` | 1400 px/с | Наибольшая скорость прокрутки у самого края. Скорость растёт плавно (квадратично) от границы зоны |
| `TICK_MAX_MS` | 48 мс | Наибольший шаг одного кадра. Защищает от скачка полосы после подвисания; обычно менять не нужно |

## Пружины

Каждое движение полосы — пружина (`spring`) с двумя параметрами:

- `dampingRatio` — затухание: 1.0 — без отскока, меньше 1 — с лёгким «перелётом» и возвратом (0.7–0.85 — мягко, ниже 0.5 — заметно пружинит);
- `stiffness` — жёсткость: больше — быстрее и резче, меньше — медленнее и плавнее (200 — неторопливо, 400 — средне, 1500 — почти мгновенно).

| Константа | Сейчас | Что двигает |
|---|---|---|
| `PART_SPRING` | 0.85 / 420 | Остальные карточки, раздвигающиеся под переносимую, и рамку места |
| `ZOOM_SPRING` | 1.0 / 260 | Уменьшение полосы при взятии карточки и возврат к обычному размеру после отпускания |
| `LAND_SPRING` | 0.78 / 320 | Подъём карточки при взятии и её посадку на место после отпускания |

Если карточки «разбегаются» слишком резко, уменьшите `stiffness` у `PART_SPRING`. Если посадка пружинит слишком
сильно, поднимите `dampingRatio` у `LAND_SPRING` ближе к 1.0.

## Лента во времени (под полосой карточек)

Лента показывает тот же проект по длине: сверху куски шириной в свою длительность (с кадром внутри), под ними
дорожка музыки в том же масштабе, через обе — линия текущего времени. Порядок меняется только на карточках; лента
перестраивается сама. Вся арифметика — в `ui/TimelineGeometry.kt` (чистые функции, `TimelineGeometryTest`).

| Что делает | Как |
|---|---|
| Масштаб | По умолчанию весь проект по ширине (`fitZoom`); щипок двумя пальцами — до `TIMELINE_MAX_PX_PER_MS`, вокруг точки между пальцами |
| Прокрутка | Один палец по ленте (по видео-дорожке), с инерцией — `Modifier.scrollable` |
| Линия времени | По абсолютному времени плеера; пока играет и ленту не трогают — лента едет за ней |
| Тап | По видео-дорожке — перемотка в это место проекта (по музыкальной — сдвиг трека) |
| Музыка | Волна и удары начинаются с `music.offsetMs`; перетаскивание по музыкальной дорожке сдвигает трек — запись одна, при отпускании |

| Константа | Сейчас | Что делает |
|---|---|---|
| `TIMELINE_VIDEO_H` | 56 dp | Высота видео-дорожки |
| `TIMELINE_MUSIC_H` | 44 dp | Высота дорожки музыки |
| `TIMELINE_JOINT` | 2 dp | Зазор между кусками (стык) |
| `TIMELINE_EDGE` | 12 dp | Отступ у начала и конца ленты |
| `TIMELINE_MAX_PX_PER_MS` | 0.4 | Предел приближения: 400 px на секунду. Больше — точнее сдвиг музыки пальцем, но меньше проекта видно |
| `TIMELINE_FOLLOW_SHARE` | 0.33 | Где стоит линия времени при автопрокрутке (доля ширины слева) |
| `TIMELINE_FOLLOW_PAUSE_MS` | 1500 мс | Сколько после касания лента не следует за временем |
| `TIMELINE_BAR_EVERY` | 4 | Каждый N-й удар — начало такта (толще), как на дорожке музыки |
| `TIMELINE_OFFSET_TAIL_MS` | 1000 мс | Насколько близко к концу трека можно сдвинуть его начало |
